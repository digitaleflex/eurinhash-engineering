# Engineering Roadmap

## North Star

Become capable of taking a real problem from **idea → architecture → implementation → cloud deployment → security → observability → operation**, with AI and automation used where they create measurable leverage.

## Tracks

### 01 — Foundations
Linux, networking, Git, HTTP/TLS, databases, scripting.

### 02 — Software Engineering
TypeScript, backend architecture, APIs, PostgreSQL, testing, modular design.

### 03 — Cloud & DevOps
Docker, CI/CD, infrastructure as code, cloud networking, IAM, observability.

### 04 — Cybersecurity
Application security, identity, threat modeling, hardening, vulnerability management, incident response.

### 05 — Cloud Native
Kubernetes, containers, networking, RBAC, policies, scaling and reliability.

### 06 — AI Engineering
LLM APIs, RAG, tool calling, agents, evaluation and production integration.

### 07 — AI Security
Prompt injection, data leakage, tool authorization, agent identity, RAG security and governance.

### 08 — Architecture
Distributed systems, event-driven design, resilience, ADRs, cost and operational trade-offs.

## Project Progression

```text
Research → Experiment → Lab → Project → Deploy → Secure → Operate → Case Study
```

## Rule

Only one primary project is actively developed at a time. Ideas remain in the backlog until the current priority is completed or explicitly stopped.
