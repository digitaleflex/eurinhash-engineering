# Eurin Hash — Engineering Laboratory

Personal public engineering laboratory dedicated to **Cloud, Cybersecurity, DevSecOps, AI, AI Security and Distributed Systems**.

This repository is not a collection of notes. It is a traceable engineering system where research is progressively transformed into experiments, labs, projects and portfolio case studies.

## Engineering Loop

```text
QUESTION → RESEARCH → SYNTHESIS → EXPERIMENT → LAB → PROJECT → DEPLOYMENT → CASE STUDY → PORTFOLIO
```

## Domains

- Cloud & Cloud Architecture
- Cybersecurity
- DevSecOps
- Kubernetes & Cloud Native
- AI Engineering
- AI Security
- Distributed Systems
- Infrastructure & Platform Engineering

## Maturity Model

| Level | Meaning |
|---|---|
| Research | Topic studied and sources collected |
| Understood | Concepts synthesized in my own words |
| Experimented | Hypothesis tested hands-on |
| Implemented | Working implementation exists |
| Deployed | Running in a real environment |
| Secured | Threats, controls and validation documented |
| Production | Operational constraints and observability addressed |
| Case Study | Results documented for portfolio use |

## Repository Structure

```text
research/        Research notes and technical investigations
labs/            Hands-on learning environments
experiments/     Focused technical experiments
architectures/   Reference architectures, diagrams and ADRs
projects/        End-to-end engineering projects
playbooks/       Repeatable operational and security procedures
portfolio/       Curated case studies and demonstrable outcomes
```

## Principles

1. **Build before over-learning.**
2. **Prefer fundamentals over tool collecting.**
3. **Document decisions, not just commands.**
4. **Security is part of architecture, not a final step.**
5. **Use complexity only when the problem justifies it.**
6. **Every serious project should produce evidence.**
7. **Research must eventually lead to action or a documented conclusion.**
