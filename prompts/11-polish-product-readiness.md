# 11 — Polish & Product Readiness

## Mission
Transformer une UI fonctionnelle en expérience EurinHash cohérente et durable.

## Prompt
Effectue la passe finale de product polish sur `eurinhash-opencode`.

Inspecte :
- cohérence visuelle ;
- hiérarchie ;
- densité ;
- micro-interactions ;
- états vides/loading/error ;
- libellés ;
- raccourcis ;
- responsive terminal ;
- accessibilité ;
- performance ;
- stabilité ;
- personnalisation ;
- documentation.

Compare l'expérience obtenue avec la vision EurinHash : le chat reste central, l'agent est compréhensible, l'activité est utile, le contexte est lisible et l'observabilité ne domine jamais l'expérience.

Élimine les informations redondantes et les composants qui n'apportent pas de valeur. Vérifie que chaque état possède un rendu explicite et que les états inconnus restent honnêtement inconnus.

### Livrables
- `docs/course/11-polish-product-readiness.md`
- polish checklist ;
- before/after findings ;
- known limitations ;
- product readiness report ;
- prochaine liste de problèmes UX réels observés en utilisation.

## Gate
La version est prête pour une utilisation quotidienne lorsque l'interface est cohérente, compréhensible et stable dans les scénarios réels.
