# Contributing

This repository is primarily a personal engineering laboratory, but useful corrections, references and technical discussions are welcome.

## Standards

- Prefer primary and authoritative sources.
- Separate facts, observations, hypotheses and opinions.
- Reproduce experiments when practical.
- Record environment, assumptions and limitations.
- Never commit secrets, credentials or private data.
- Security research must remain legal, authorized and responsible.

## Documentation

Use the templates in `docs/templates/` for new research, experiments, labs, projects and architecture decisions.
